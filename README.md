# Restaurant Queue Management System (ระบบจัดการคิวร้านอาหาร)

ระบบจัดการคิวร้านอาหารแบบ Command Line Interface (CLI) พัฒนาด้วยภาษา Python โดยใช้หลักการ Object-Oriented Programming (OOP) ร่วมกับการจัดการไฟล์เพื่อบันทึกข้อมูลคิวอย่างต่อเนื่อง

## 📌 คุณสมบัติของระบบ (Features)

* **[1] New Queue**: รับคิวใหม่ จัดหมวดหมู่อัตโนมัติและรันเลขคิวตามจำนวนลูกค้า
  * **หมวด A (Small Queue)**: สำหรับ 1 - 2 คน
  * **หมวด B (Medium Queue)**: สำหรับ 3 - 4 คน
  * **หมวด C (Large Queue)**: สำหรับ 5 คนขึ้นไป
* **[2] Next Queue**: เรียกคิวถัดไปออกมารับบริการ พร้อมอัปเดตไฟล์ข้อมูลอัตโนมัติ
* **[3] All Queue**: แสดงรายการคิวทั้งหมดที่กำลังรออยู่ในระบบ
* **[4] Cancel Queue**: ระบุหมายเลขคิวเพื่อยกเลิกคิวเฉพาะราย
* **Auto Sync System**: อ่านไฟล์คิวล่าสุดตอนเปิดโปรแกรม เพื่อรันเลขคิวต่อให้อัตโนมัติ ป้องกันปัญหาเลขคิวซ้ำ

## 📁 โครงสร้างไฟล์ใน Repository

* `Restarant_Queue_Management.py` : โค้ดหลักของระบบจัดการคิวร้านอาหาร
* `Flowchart_ver_txt.txt` : อธิบายขั้นตอนการทำงานของระบบในรูปแบบตัวอักษร
* `data.txt` / `queue.txt` : ไฟล์สำหรับจัดเก็บข้อมูลคิวแบบ Pipe-delimited (`|`)
* `handling_file_testing.py` : สคริปต์สำหรับการทดสอบระบบ File I/O

## 🚀 วิธีการใช้งาน (Usage)

1. **ติดตั้ง Python**: ตรวจสอบว่าเครื่องคอมพิวเตอร์มีการติดตั้ง Python 3.x เรียบร้อยแล้ว
