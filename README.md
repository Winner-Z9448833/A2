## 3. ภาพรวมโปรแกรม (Project Overview)
โปรแกรม **Restaurant Queue System** พัฒนาขึ้นด้วยภาษา Python เพื่อช่วยอำนวยความสะดวกในการบริหารจัดการคิวของร้านอาหาร โดยระบบสามารถแบ่งประเภทโต๊ะตามจำนวนลูกค้า รับจองคิว บันทึกข้อมูลลงในไฟล์ข้อความโดยอัตโนมัติ เรียกคิวถัดไปบริการ และยกเลิกคิวได้อย่างมีประสิทธิภาพ

---

## 4. องค์ประกอบการเขียนโปรแกรมตามโครงสร้างหลัก

### 4.1 Object-Oriented Programming (OOP)
โปรแกรมนี้มีการออกแบบโครงสร้างเชิงวัตถุอย่างเป็นระบบ ดังนี้:
* **Base Class (`QueueItem`):** คลาสหลักที่ทำหน้าที่เก็บข้อมูลพื้นฐานของคิว ประกอบด้วย `QueueNo` (หมายเลขคิว), `name` (ชื่อลูกค้า), `phone` (เบอร์โทรศัพท์), และ `party_size` (จำนวนคน) พร้อมเมธอด `strfile()` สำหรับจัดรูปแบบข้อมูลเพื่อบันทึกลงไฟล์
* **Inheritance (การสืบทอดคุณสมบัติ):** มีการสร้างคลาสลูก 3 คลาสที่สืบทอดมาจาก `QueueItem` เพื่อแยกประเภทขนาดโต๊ะอัตโนมัติ:
  * `SmallQueue`: สำหรับลูกค้า 1–2 คน (เติม Prefix นำหน้าด้วยตัวอักษร `"A"`)
  * `MediumQueue`: สำหรับลูกค้า 3–4 คน (เติม Prefix นำหน้าด้วยตัวอักษร `"B"`)
  * `LargeQueue`: สำหรับลูกค้ามากกว่า 4 คนขึ้นไป (เติม Prefix นำหน้าด้วยตัวอักษร `"C"`)

### 4.2 Arrays / Lists & Data Structures (โครงสร้างข้อมูลแบบรายการและเมทริกซ์)
* **2D Array (`queue_matrix`):** ใช้เก็บรายการคิวทั้งหมดที่โหลดมาจากไฟล์หรือถูกเพิ่มเข้ามาใหม่ในรูปแบบ List ซ้อน List (`[ [QueueNo, name, phone, party_size], ... ]`)
* ใช้ฟังก์ชันการจัดการ List เช่น `.append()` สำหรับเพิ่มคิวใหม่ และ `.pop(0)` เพื่อดึงคิวแรกสุดออกเมื่อเรียกคิวถัดไป

### 4.3 Functions, Methods & Control Structures (ฟังก์ชัน การวนลูป และเงื่อนไข)
* **การจัดการไฟล์ (File Handling):** ใช้คำสั่ง `open()` ร่วมกับโหมด `"r"`, `"w"`, และ `"a"` ในการอ่านและเขียนข้อมูลลงในไฟล์ `queue.txt` อย่างปลอดภัย พร้อมใช้ `try-except` ป้องกันข้อผิดพลาดกรณีที่ยังไม่มีไฟล์ข้อมูล
* **การควบคุมลูป (While Loop & If-Else):** ใช้ `while True` ควบคุมเมนูหลักให้ทำงานวนซ้ำจนกว่าผู้ใช้จะเลือกกด `[0]` เพื่อออกจากโปรแกรม และใช้เงื่อนไขตรวจสอบขนาดจำนวนคน (`amount`) เพื่อเลือกสร้างประเภทคิวที่ถูกต้อง

### 4.4 Modules & Built-in Functions
* ใช้ฟังก์ชันพื้นฐานของ Python เช่น `strip()` สำหรับตัดช่องว่าง, `split("|")` สำหรับแยกข้อมูลคั่นด้วยเครื่องหมายขีดตั้ง, และการแปลงชนิดข้อมูล (`int()`, `str()`) เพื่อความถูกต้องในการประมวลผลตัวเลขลำดับคิว (`count_a`, `count_b`, `count_c`)
